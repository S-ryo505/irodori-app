# カゾスケ（家族カレンダー Android版・旧いろどり）

## スマホに入れる
1. スマホのブラウザでこのリポジトリの **Releases**（右側）を開く
2. いちばん上の `kazosuke.apk` をタップしてダウンロード → 開いてインストール
3. 2回目以降も同じ手順で上書きインストール（データは消えません）

## できること
- 月・週（月〜日の7列、日曜は次の週）・日（時間軸）の表示、全員分を色分け
- 予定にコメント・写真、習い事テンプレートで毎週自動登録
- 給食/お弁当、部活の予定表をJSON貼り付けで取り込み
- 天気（現在地）と予定に合わせたアドバイス、キャラの読み上げ（HTML/GLB/画像を読み込み可）
- お買い物チェックリスト、ToDo、ストックの日数管理
- 朝「きょうの予定」・夜「あしたの予定」の通知
- ホーム画面ウィジェット：きょう / 週 / 月 / 買い物・ToDo（ウィジェット上でチェック可）
- Firebaseで家族共有（Web版いろどりとデータ互換）

## 作り方
main に push すると GitHub Actions が APK を作り、Releases に置きます（`.github/workflows/build-apk.yml`）。
